# EDD-I Orai Dashboard

Billing & revenue dashboard for EDD-I Orai (DIV233422), DVVNL — web version and installable mobile app.

**Open:** https://chauhannagendra005-bit.github.io/edd1-orai/

- Phones: open the link in Chrome → enter the office passphrase → **Install app**.
- PCs: open the link in Chrome / Edge.
- The app is password protected: the password (the office passphrase) is asked every time it opens and after 10 minutes away. Data stored on the phone is kept encrypted.

This repository holds only the app. Consumer data is published daily by the office PC into `live/`,
**encrypted** (AES-256) — it cannot be read without the office passphrase.
